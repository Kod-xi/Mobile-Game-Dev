Title: Dash Runner
One line pitch: Endless runner with aerial combat
Aesthetics (target player feelings/experiences)
Fast, skillful, satisfying.
Core mechanics (3–5 verbs/systems)
Tap to jump, swipe to dash, tap mid-air to attack. Dashes can be cancelled into attacks.
Dynamics 
The player runs endlessly to the right using attacks and dashes to build up score.
When in the air, the player can attack, if the attack hits an enemy, the player can then perform a mid-air dash to try to hit another enemy. Performing this attack -> dash -> attack -> dash cycle multiple times will start a combo which quickly increases their score.
Progression & content 
Unlockable characters with unique attacks
Run length: 3-5 min
High score leaderboard
Platform features (haptics, safe-area handling; store/testing tracks = awareness only)
Performance budget (target frame-time, memory, load time)
Target 60fps
Monetisation (if any) & ethics notes
